# 저장: 앱 주인(서버를 띄운 사람)의 컴퓨터에 남겨서 공유하기

저장 방식: **랠리 기록 + 하이라이트 영상(랠리 구간만, HUD 겹친 채)**, 공유 링크로 보기. 아래대로 구현됨(`save-server.js`, `public/js/recorder.js`, `public/js/app.js`, 설정·기록 화면).

## 구현된 것 (설계와 다른 점 포함)

- 열쇠 전달: 1회용 설정 링크로 전달한다. `bun scripts/make-setup-link.mjs`가 새 링크를 `~/.config/pingpong-vision/setup-link.txt`(0600)에만 쓴다(화면에 안 찍음). 링크는 `…/vision/#setup=<토큰>`, 10분 만료, 한 번 쓰면 무효(다시 열면 "설정 링크가 이미 쓰였거나 시간이 지났어요"). 앱이 열리자마자 주소창에서 `#` 부분을 지우고 `POST /vision/api/setup`으로 한 번 바꿔 열쇠를 폰에 저장한다. 서버 디스크엔 토큰의 sha256과 만료 시각만 남는다. 이미 앱이 열려 있는 탭에 링크가 들어와 주소의 `#` 부분만 바뀌어도(`hashchange`, 뒤로 가기 캐시 복원 `pageshow`) 똑같이 바꾼다. `#setup` 뒤가 잘리거나 바뀌어 모양이 틀리면 조용히 넘어가지 않고 "설정 링크 모양이 달라요"를 띄운다. 안내 문구는 버튼 아래 첫 화면 밖에 있어서, 새 안내가 뜨면 그 줄까지 스크롤해 보이게 한다. 시험: `qa/sw-update-e2e.mjs`(옛 서비스 워커가 깔린 상태의 첫 열기 포함).
- 열쇠: 서버가 처음 켤 때 `~/.config/pingpong-vision/upload-key`(0600)에 만든다. 사용자는 앱 **설정 → PC 저장 열쇠**에 한 번 붙여 넣는다(서버가 `/api/key-check`로 맞는지 확인). 설계의 `?save=` 링크 방식 대신 직접 입력으로 했다(주소창·기록에 열쇠가 남지 않게).
- 녹화: 랠리가 시작될 때 `MediaRecorder`로 시작, 랠리가 끝나면 멈춘다. 카메라 화면 + 화면의 HUD(뼈대·궤적·LOCK·라벨) + 맨 위 점수 줄을 960 px 폭 캔버스에 그려 녹화. mp4(H.264)가 되면 mp4, 아니면 WebM. 한 클립 최대 14초(Safari 26 mp4 녹화가 15초 넘으면 멈춘 화면이 되는 버그 https://bugs.webkit.org/show_bug.cgi?id=315091 때문).
- 올리기: 기록 저장 조건과 같이 샷 2개 이상·바운드 1개 이상인 랠리만. 랠리 구간 밖 영상은 녹화 자체를 안 한다. 기록 화면에 "올리는 중 / 올림 / 못 올림", 올리면 "공유 링크"와 "지우기".
- 받는 쪽 확인: 영상 형식은 업로드가 말하는 형식이 아니라 파일 머리(mp4 `ftyp`, WebM EBML)로 판단.
- 지우기: 기록의 "지우기"가 PC의 폴더를 지운 뒤(열쇠 필요) 폰 기록에서도 지운다. 지운 링크는 404.
- 상한: 영상 200 MB, 기록 1 MB, 최대 300개, 합계 5 GB, 시간당 60번.

## 지금 원칙과의 관계

- 지금 앱은 "영상은 폰 밖으로 나가지 않는다"를 지키고, 서버에 받는 경로가 아예 없다(`server.js`).
- **기록만**(랠리 시간·샷 수·속도·바운드 위치·MOVE, 숫자 JSON)은 영상이 아니어서 이 원칙과 부딪히지 않는다.
- **하이라이트/전체 영상**은 원칙을 바꾸는 일이다. 사용자가 직접 고른 경우에만, 설정에서 사용자가 켰을 때만 보낸다(기본 꺼짐). 다른 사람 얼굴이 찍힐 수 있다는 안내를 켤 때 한 번 보여 준다.

## 받는 자리

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 서버 | 앱 서버(HTTPS 역방향 프록시/터널 뒤) | 기존 `/vision` 아래에 둔다. 대회 앱은 그대로. |
| 주소 | `POST /vision/api/save/<비밀값>` (받기), `GET /vision/s/<비밀값>/` (사용자용 목록·내려받기·공유) | 인터넷에 공개된 주소이므로, 추측할 수 없는 비밀값이 경로에 있어야만 열린다. |
| 비밀값 | 32바이트 난수(base64url 43자). `~/.config/pingpong-vision/save-token`에 두고, 서버가 처음 켤 때 없으면 만든다. | 로그인 화면 없이 앱 주인(서버를 띄운 사람)만 쓰는 링크. 유출되면 파일을 지우고 새로 만들면 끝. |
| 폰에 링크 넣기 | 사용자에게 한 번 `…/vision/?save=<비밀값>` 링크를 준다. 앱이 그 값을 폰 저장소에 넣고 주소창에서 지운다. | 사용자 기기에 설치·로그인 없이. |
| 저장 위치 | `~/pingpong-vision-saves/YYYY-MM-DD/HHMMSS-<종류>.(json|mp4|webm)` | 날짜별로 앱 주인이 컴퓨터에서 바로 찾을 수 있게. 저장소(git)·공개 폴더 밖. |
| 크기 제한 | 기록 1 MB, 하이라이트 200 MB, 전체 영상 2 GB(사용자가 고를 때만) | 프록시·디스크 보호. 넘으면 413과 한국어 안내. |
| 공유 | 목록 페이지에서 파일마다 "공유 링크 만들기": 따로 만든 짧은 비밀 링크 `GET /vision/f/<파일비밀값>` (7일 뒤 만료, 언제든 취소) | 전체 목록 권한을 남에게 주지 않고 파일 하나만 보낼 수 있게. |
| 지우기 | 목록에서 지우기, 30일 자동 삭제(사용자가 켤 때) | 남의 얼굴이 담긴 영상을 오래 두지 않게. |
| 보안 | 비밀값 없는 요청 404, 같은 출처만(CSP `connect-src 'self'` 그대로), 업로드는 Content-Type 확인, 파일 이름은 서버가 만든다(사용자 입력 안 씀), 경로 탐색 차단, 분당 요청 수 제한 | 인터넷에 열린 받는 경로의 기본 방어. |

## 앱 쪽 흐름

1. 정지하면 랠리 기록이 지금처럼 폰에 남는다.
2. 비밀값이 있으면 "PC에 저장" 버튼이 기록 화면에 생긴다. 누르면 기록 JSON을 보낸다(기록만인 경우 자동 저장도 가능).
3. 영상이 허락되면: 카메라 영상을 `MediaRecorder`로 폰 안에서 녹화하고, 랠리 구간(시작 0.5초 전 ~ 끝 0.5초 뒤)만 잘라 하이라이트로 보낸다. 아이폰 Safari는 `video/mp4`(H.264)로 녹화된다. 보내는 중 진행률, 실패 시 다시 보내기.

## 남은 결정 (사용자가 정함)

- 올릴 것: 기록만 / 하이라이트 영상 / 전체 영상.
- 자동 저장 여부, 보관 기간.
